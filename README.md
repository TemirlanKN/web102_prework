# Android Prework - *Sea Monster Crowdfunding*

Submitted by: **Temirlan Kdyrkhan**

**Sea Monster Crowdfunding** is a simple website project that showcases a fictional crowdfunding campaign for a “Sea Monster” idea. The page includes images, text descriptions, and interactive elements that simulate real-life crowdfunding functionality. This project is a direct clone of the original website found at Sea Monster Crowdfunding.

Time spent: **5** hours spent in total

## Required Features

The following **required** functionality is completed:

* [X] Display Game Cards: Each game is displayed with key details (image, title, description, funding status).
* [X] Filter Buttons: Users can toggle between funded, unfunded, and all games.
* [X] Statistics Section: Displays total contributions, money raised, and the number of games.
* [X] Responsive Design: The website adapts to various screen sizes.

The following **optional** features are implemented:

* [X] Search Bar: Allows users to search for games by name.
* [X] Improved Aesthetics: Additional CSS enhancements for a modern look.
* [X] User Interactions: Hover effects and animations for better user experience.

## Notes

Challenges and Learnings
Challenges:

* Understanding and implementing JavaScript array methods like filter, reduce, and map for dynamic content generation.
* Designing a responsive layout using CSS Flexbox and Grid.
* Debugging event listener issues for the filter buttons.

## Learnings:
